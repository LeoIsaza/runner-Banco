Esta carpeta es un destino de ejemplo, vacio, solo para que la Run
Configuration de IntelliJ incluida en el proyecto ("Generar feature -
ejemplo jsonplaceholder") tenga donde escribir al correr por primera vez,
sin que tengas que configurar nada.

En un uso real, reemplaza el valor de la variable de entorno
"pathRelativeFolder" (en Run > Edit Configurations) por la ruta real de TU
proyecto Karate destino, por ejemplo:
  /Users/tu-usuario/repos/mi-proyecto-karate/src/test/java/integration
